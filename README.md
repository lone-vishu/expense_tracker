# Expense Tracker (Python Project)

A command-line based Expense Tracker built using Python to help users manage and track their daily expenses.

This project allows users to:
- Add expenses
- View expense records
- Search expenses
- Delete expenses
- View spending summary

The project focuses on practical implementation of Python fundamentals and structured programming concepts.

---

## 📌 Project Overview

The Expense Tracker provides a menu-driven interface where users can efficiently manage expense records.

### Features:
- Add expense details
- Automatically store current date
- View all expenses
- Search expenses by:
  - Date
  - Category
  - Note
  - Amount
- Delete expense records
- View total and maximum spending summary
- Handle invalid inputs using exception handling

Each expense record contains:
- Date
- Category
- Amount
- Note
